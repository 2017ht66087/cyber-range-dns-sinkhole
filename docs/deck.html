Rules

The range never leaves the lab

Traffic

Synthetic only

DNS beacons, HTTP check-ins, and an inert C2 “sleep” task. No real malware or exfil.

Network

No real internet

Public names resolve to fake-web. C2 names resolve to fake C2. Egress is denied.
